# Terrain development archive

Historical source staging copies, compiler outputs, diagnostics, and backups moved from the MappyX project's Assets/MGTerrainImplementation~ directory.

The active terrain implementation lives in this SDK's Runtime, Editor, and Shaders directories. These archived copies are not imported by Unity. Do not install older snapshots over the active implementation.

Compiler response files and diagnostics retain historical absolute paths; regenerate them before reuse. Project-specific scene backups are retained here for recovery, not as SDK runtime content.
