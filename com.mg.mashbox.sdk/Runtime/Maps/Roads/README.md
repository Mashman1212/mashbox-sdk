# MashBox Road Tool

Open **MashBox > SDK > Map Tools > Road Tool - Road Networks**, or **MashBox > Map Tools > Road Tool**.

1. Create a Road Network. Set default width and road/shoulder materials in Network.
2. In Terrain, assign an MG Terrain World and choose the default terrain mode.
3. Create a New Road or New Loop. Hold Shift in Scene view for a live road-surface preview, then Shift-click to place a point at the nearest open end (start or end). Closed loops extend from their last knot. Surfaces with colliders are used for placement; otherwise the fallback horizontal plane is used.
4. Select a point and drag its handles. Ctrl-click splits the nearest curve without changing its shape. Ctrl takes priority over Shift. Plain clicks select points or objects and do not create knots. Delete removes the selected point; Escape stops drawing. Unity's normal spline tools remain available for tangent editing.
5. Set width, shoulders, crown, banking, sampling, collider, materials and UV metres/offset/swapping in the road inspector. Each road uses one center spline.

Roads inherit network terrain settings unless Override Terrain is enabled. Independent leaves the spline at its authored height. Road Follows Terrain projects generated surface samples onto the assigned world's readable MG terrain meshes, preserving the source spline. Moving the road or network updates its surface. Rebuild after external terrain edits.

Terrain Follows Road uses non-destructive terrain layers. **Apply Terrain** replaces each selected road layer, restoring its old footprint. **Auto Apply Terrain** updates during dragging, with updates coalesced and an adaptive pause between passes to keep the editor responsive; per-road overrides also support this option. Layers store sampled target heights and weights separately from the base terrain, so repeated partial-strength Apply does not accumulate. Overlapping roads compose in hierarchy order. Disabled/deleted roads remove their contribution. Height offsets, falloff, strength, raise-only/lower-only and Undo/Redo are supported. Existing direct terrain imprints from older tool versions are part of the initial baseline; they cannot be reconstructed automatically.

Meshes are baked automatically to `Assets/MashBox Roads/Generated` when saving a scene, so renderers and colliders survive reload and player builds. Duplicated roads receive independent mesh assets. Save the scene before exporting it. Deleted roads may leave unused baked assets; remove those only after checking references.

The network currently groups authoring and terrain settings. It does not generate intersection meshes, traffic routing, or junction blending. Roads crossing one another retain their own surfaces. Tight curves can fold if the width exceeds the bend radius.

Run **MashBox > Validation > Validate Roads** for geometry, insertion, terrain following, terrain Apply/Undo/Redo, and independent mesh persistence checks in a temporary preview scene.

Road Apply always conforms the complete road/shoulder footprint plus one local terrain-cell span before the configured falloff begins. One cell supports triangles crossing the road edge, and an additional cell creates a full-height apron before blending. The cell span uses the longest incident triangle edge in the horizontal plane, conservatively including diagonal cells and adapting to terrain resolution. This also applies to existing roads that previously disabled Match Terrain Cells. Strength and raise/lower restrictions still apply. Apply reports the changed vertex count and largest height change.

Select a knot in Edit in Scene: W moves in the road-aligned knot frame; E rotates the knot (roll banks the road; yaw/pitch redirect its tangents); R scales width and shoulders on X, crown/drop on Y, and tangent length on Z. Rotation or tangent scaling switches that knot to Broken tangents for manual control. Knot scale lives in the spline's embedded data, interpolates along each segment, and supports Undo. Preview and generated geometry use the same cross section.

**Remove Terrain Layers** restores the underlying terrain and pauses those roads until Apply is pressed again. **Bake All Road Layers in Terrain World** flattens all road layers in the assigned world into the visible mesh, discards their authoring history, and pauses their automatic updates. Bake supports Undo. Independent sculpt deltas are retained in the underlying terrain when layers update or are removed. Bake/remove layers before changing terrain topology or resolution.

Live road editing keeps newly created terrain meshes in memory and does not create/import assets. Save or Bake persists them. Save the scene after editing: conformed terrain is stored as a persistent, tile-owned mesh asset, while reversible baseline and layer data remain in the editor scene. Building strips the layer component and its data from the build scene; gameplay reads the final terrain mesh and collider without reconstructing or replaying road strokes. Explicit Bake is optional for gameplay and is only needed when you want to discard the editor history.

Run **MashBox > Validation > Validate Road Terrain Layers** for isolated preview-scene checks of layer replacement, overlapping roads, live movement, independent sculpt changes, Undo/Redo, serialization, removal, baking and build stripping.
Smooth Falloff averages transition heights while pinning the full-strength roadbed, unaffected vertices and tile/open boundaries. Amount and pass count are adjustable. Minimum Falloff Cells (default 6) expands short falloffs on coarse terrain; zero retains the exact meter distance. Disable Smooth Falloff for the previous behavior. Smoothing is stored with each reversible layer and is rebuilt from layer inputs, never accumulated into the base terrain. Apply existing roads once to update their stored layers.

Terrain layer smoothing caches mesh connectivity and reuses working buffers. Undo clears the cache and changed topology invalidates it. Road surface lookup searches nearby bounding-tree nodes first. Profiler markers MGRoadLayer.Sample, MGRoadLayer.Evaluate and MGRoadLayer.Compose separate the remaining costs; MGRoadLayerService.LastApplyMilliseconds reports the latest complete Apply time.

The Road Tool and road/network inspectors have a **Details** tab. **Clear Details** opts into reversible clearing of all painted Terrain World density-detail layers (including palette-generated foliage). **Auto Update** follows road edits; disable it for manual Apply. **Extra Width** expands beyond the rendered road and shoulders, independently of terrain-height falloff. Whole touching density cells are cleared so randomized blades do not poke through; coarse detail maps can clear slightly beyond the requested margin. Per-road **Override Details** replaces network settings. This works in every road terrain mode and does not remove manually placed objects.

**Apply Detail Clearing** enables/resumes clearing for the selected road(s); if their inherited setting is off, Apply creates an enabled per-road override. **Restore Details / Pause Clearing** removes those road contributions until Apply resumes them. Turning Clear Details off, disabling or deleting a road also reveals its original paint; other overlapping road masks continue to clear their footprint. Density, size and grass-ID maps remain untouched, including painting performed while a road mask is active. Live masks use memory only; save the scene to persist the combined masks. Gameplay reads those saved masks through the same density path for CPU and GPU generation, without reconstructing road footprints. The build strips per-road authoring history.

Run **MashBox > Validation > Validate Road Detail Clearing** for generation masking, movement, overlap, independent painting, Undo/Redo, manual updates, different map resolutions, serialization and build stripping checks.
